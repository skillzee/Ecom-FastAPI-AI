# Everyday project pack

Created from the repository implementation on 11 October 2026.

- **Everyday-LLD.pdf**: 12-page low-level design with rendered architecture, entity, and sequence diagrams, field definitions, endpoint contracts, operational setup, and current limitations. The Markdown file is the editable source.
- **Everyday-Project-Prompt.pdf**: 6-page reusable coding prompt for the complete project baseline and future changes. The Markdown file is the editable source.
- **Everyday-Presentation.pptx**: 13-slide editable PowerPoint with source notes. The PDF is a convenient viewing copy.
- **Everyday-Poster.pdf**: one-page A3 portrait poster for printing.
- **Everyday-Poster.png**: poster image for sharing (1984 x 2806 pixels).
- **Everyday-Poster-Editable.pptx**: editable poster source.
- **Everyday-Illustration.png**: generated concept artwork used on the cover and poster. It does not depict actual inventory photographs.
- **Everyday-Artwork-Prompt.txt**: exact prompt and generation method for the illustration.

The design documents current code. Checkout saves unpaid orders. Persistent chat, payments, inventory quantities, and administrator protection for catalog writes are future work. Product sample loading is automatic; policy-PDF ingestion is manual.

Editable documentation sources also live in `docs/project/`. Build and QA files live in `tmp/project-artifacts/` and are not part of the delivery pack.
